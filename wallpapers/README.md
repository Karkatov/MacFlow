# Wallpapers — автозагружаемая галерея MacFlow

Просто положите файлы в нужную папку. Ничего в коде менять не нужно.

```
wallpapers/
├── images/     ← статичные обои: .jpg .jpeg .png .webp .avif .gif .svg
├── videos/     ← живые обои: .mp4 .webm .mov .m4v
├── posters/    ← постеры для видео (необязательно)
└── showcase/   ← видео/картинки для демо-блока (необязательно)
```

## Как это работает

1. Файлы из `images/` и `videos/` попадают в галерею на главной
   (две бесконечные бегущие строки).
2. Первое видео (по алфавиту) становится фоном интерактивного lock screen.
3. Название обоев берётся из имени файла:
   `northern-lights.mp4` → **Northern Lights**.
4. Если для видео есть постер с таким же именем в `posters/`
   (`northern-lights.jpg`), он показывается до запуска видео.
   Если постера нет — первый кадр сгенерируется автоматически (нужен ffmpeg).
5. Файлы из `showcase/` используются в блоке «Watch it in action».
   Первый видеофайл — основной ролик.

## Обновление после добавления файлов

Сайт собирается статически, поэтому после добавления обоев нужно
пересобрать сайт:

```bash
npm run dev     # пересобирает медиа-манифест при запуске
# или
npm run media   # только синхронизировать папки
npm run build   # пересобрать сайт
```

`npm run dev` и `npm run build` автоматически запускают `npm run media`
через `predev` / `prebuild`.

## Демо-файлы

В папках уже лежат демонстрационные обои с префиксом `demo-`.
Их можно удалить и заменить своими — просто не забудьте пересобрать сайт.

## Рекомендации

- Видео: H.264 MP4, 1920×1080 или 3840×2160, 6–20 секунд, без звука.
- Изображения: 2560×1600 или больше, JPG/WebP.
- Держите файлы лёгкими: 2–8 МБ на видео, 300–800 КБ на картинку.
- Имена файлов лучше писать латиницей через дефис.
