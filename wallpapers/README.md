# Wallpapers — медиа MacFlow

Просто положите файлы в нужную папку. Ничего в коде менять не нужно.

```
wallpapers/
├── gallery/
│   ├── image/        ← статичные обои для галереи
│   └── video/        ← живые обои для галереи
├── hero/
│   ├── image/        ← картинка для интерактивного экрана в hero
│   └── video/        ← видео для интерактивного экрана в hero
├── lock-screen/
│   ├── image/        ← картинка для блока «Экран блокировки»
│   └── video/        ← видео для блока «Экран блокировки»
├── demo/
│   ├── image/        ← картинка для блока «Watch it in action»
│   └── video/        ← видео для блока «Watch it in action»
└── posters/          ← постеры для видео (необязательно)
```

Поддерживаются форматы:

- изображения: `.jpg`, `.jpeg`, `.png`, `.webp`, `.avif`, `.gif`, `.svg`
- видео: `.mp4`, `.webm`, `.mov`, `.m4v`

## Что куда попадает

| Папка                                     | Где используется                                         |
| ----------------------------------------- | -------------------------------------------------------- |
| `gallery/image` + `gallery/video`         | Бегущая галерея на главной, статистика, блок с ноутбуком |
| `hero/image` + `hero/video`               | Интерактивный экран блокировки в самом верху главной     |
| `lock-screen/image` + `lock-screen/video` | Отдельный блок «Настройте свой Lock Screen»              |
| `demo/image` + `demo/video`               | Большой блок «Watch it in action»                        |
| `posters`                                 | Превью для видео до его запуска                          |

В каждой секции сначала берётся видео, если оно есть. Если видео нет — картинка.
Это позволяет держать демо, экран блокировки и hero полностью разными файлами.

## Как это работает

1. `npm run media` (автоматически в `predev` и `prebuild`) сканирует папки.
2. Копирует файлы в `public/media/` и обновляет
   `src/generated/media-manifest.json`.
3. Название обоев берётся из имени файла:
   `northern-lights.mp4` → **Northern Lights**.
4. Если для видео есть постер с таким же именем в `posters/`
   (`northern-lights.jpg`), он показывается до запуска видео.
   Если постера нет — первый кадр сгенерируется автоматически (нужен `ffmpeg`).
5. `public/media/` не коммитится — пересоздаётся при каждой сборке.

## Обновление после добавления файлов

Сайт собирается статически, поэтому после добавления медиа нужно
пересобрать сайт:

```bash
npm run dev     # пересобирает медиа-манифест при запуске
# или
npm run media   # только синхронизировать папки
npm run build   # пересобрать сайт
```

## Если папка пустая

Сайт не сломается: hero и блоки автоматически возьмут подходящее медиа
из `gallery/`. Но чтобы демо и экран блокировки не повторялись, лучше
положить для них отдельные файлы.
